✅ Must (imprescindible para un MVP funcional en 16 semanas)
  • Definir el modelo ER completo con todas las entidades y relaciones.
  • Crear migración de base de datos para `user` con autenticación y campos auditables.
  • Implementar autenticación con JWT y refresh tokens.
  • Implementar control de acceso basado en roles y permisos (RBAC).
  • Construir CRUD de `person` y enlace con `user`.
  • Crear CRUD de `continent`, `country`, `department`, `city`.
  • Cargar datos semilla para geografía (ISO).
  • Crear CRUD de `airport`.
  • Crear CRUD de `airline`.
  • Crear CRUD de `aircraft_type` y `aircraft`.
  • Crear CRUD de `route`.
  • Crear CRUD de `flight_type`, `flight_status` y `flight`.
  • Implementar `flight_schedule`.
  • Crear CRUD de `crew_role` y `crew_member`.
  • Implementar `crew_assignment`.
  • Crear CRUD de `passenger`.
  • Crear CRUD de `reservation`.
  • Crear CRUD de `ticket_class` y `ticket`.
  • Implementar emisión de `ticket` a partir de `reservation`.
  • Crear CRUD de `baggage`.
  • Implementar `checkin` online básico.
  • Diseñar API REST v1 con OpenAPI/Swagger.
  • Añadir paginación, ordenamiento y filtros en endpoints.
  • Implementar validación y sanitización de entrada.
  • Construir pruebas unitarias básicas.
  • Configurar CI/CD básico (lint + tests).
  • Contenerizar servicios con Docker y `docker-compose`.
  • Documentación técnica mínima (modelo + API).
🟡 Should (importante, pero puede ir después del MVP)
  • Validar políticas de contraseña y recuperación segura.
  • Implementar búsqueda y filtros avanzados en geolocalización.
  • Crear CRUD de `terminal`, `boarding_gate`, `runway`, `maintenance_facility`.
  • Implementar validación de conflictos en `flight_schedule`.
  • Implementar selección de asientos en `reservation`.
  • Implementar política de equipaje según `ticket_class`.
  • Generar código QR/barras para pase de abordar.
  • Implementar reglas automáticas de `flight_status`.
  • Implementar auditoría en tablas.
  • Implementar soft-delete.
  • Añadir índices compuestos.
  • Construir pruebas de integración.
  • Implementar logs estructurados y trazabilidad.
  • Añadir endpoints `/health` y `/ready`.
  • Implementar rate limiting.
  • Añadir CORS configurable.
  • Implementar caché para catálogos.
  • Preparar dataset semilla para QA.
🟢 Could (nice to have, no bloquea el MVP)
  • Implementar proceso de reacomodación por vuelos cancelados.
  • Implementar cálculo de tiempos de conexión.
  • Implementar verificación de conflictos de `runway`.
  • Implementar mantenimiento preventivo de `aircraft`.
  • Implementar notificaciones a pasajeros (email/SMS).
  • Internacionalización (i18n).
  • Diseñar estrategia de versionado de API.
  • Implementar backups automáticos.
  • Implementar servicio de cálculo de tarifa base + impuestos.
  • Implementar búsqueda de vuelos avanzada.
  • Implementar disponibilidad de asientos en tiempo real.
  • Endpoint para historial de `flight_status`.
  • Verificación de identidad en checkin.
  • Monitoreo de tiempos de respuesta y alertas.
  • Retención/anonimización de datos personales.
  • Endpoints de reportes (`ocupación`, `puntualidad`, `equipaje`).
  • Pruebas E2E completas.
  • Idempotencia en operaciones críticas.
  • Validación de huso horario.
  • Exportación CSV/JSON.
❌ Won't (fuera del alcance de 16 semanas)
  • Implementar rebooking avanzado con integración externa.
  • Notificaciones reales con proveedor SMS/email.
  • Módulo avanzado de mantenimiento preventivo de `aircraft`.
  • Reportes BI avanzados y dashboards en tiempo real.
  • Integración con pasarelas de pago.
  • Multi-tenant / despliegues multi-aerolínea.
